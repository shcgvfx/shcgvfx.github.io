# SHVFX - Rigger Portfolio

A lightweight GitHub Pages site built with plain HTML and CSS.

## Publish on GitHub Pages

The repository is `shcgvfx.github.io`. Publish the `main` branch from the repository root.

## Project progress logs

- The first project card opens `project-01.html`.
- Store progress images in `assets/project-01/`.
- Add timeline entries in `project-01.html`, oldest first, with captions in this format: `STEP 01: Title - YYYY-MM-DD`.
- Duplicate a project card in `index.html` to add more project slots.
