# SHVFX — Rigger Portfolio

A lightweight GitHub Pages site built with plain HTML and CSS.

## Publish on GitHub Pages

1. Create a public repository named `shcgvfx.github.io` under the `shcgvfx` GitHub account.
2. Push these files to the repository's `main` branch.
3. In repository settings, choose **Settings → Pages → Deploy from a branch**, then select `main` and `/(root)`.
